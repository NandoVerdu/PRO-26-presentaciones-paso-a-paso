Crea una página HTML interactiva y animada con los dos archivos que te adjunto:
estilo.md dice cómo se ve y el otro dice qué contiene.
No añadas datos que no estén ahí. Si falta alguno, escribe «pendiente».

Reglas:
- Un solo bloque de código, de <!DOCTYPE html> a </html>, con el CSS y el JavaScript dentro y sin frameworks.
- Todo cabe en 1280 x 720, sin barras de desplazamiento. Usa html { font-size: min(1.25vw, 2.2222vh) } y medidas en rem.
- Texto de 20 px o más.
- Deja libre la esquina inferior derecha (130 x 90 px).
- Funciona con ratón, con el dedo y con el tabulador. No uses las flechas izquierda y derecha.
- No uses localStorage, sessionStorage, alert, prompt, confirm ni window.open.
- No escribas <? ni ?>.
- Imágenes: solo SVG dibujado en el código o direcciones https.
- Respeta prefers-reduced-motion.
