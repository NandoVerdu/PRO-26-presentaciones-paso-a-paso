5 Pestaña «Config»

En la columna B escribe el nombre de tu microempresa (titulo) y el tuyo (autores). Elige el tema.

6 Implementar

Implementar → Nueva implementación → Aplicación web · Ejecutar como: Yo · Acceso: Cualquier usuario con una cuenta de Google. Copia la URL /exec y guárdala.

Esto se hace una sola vez. Cuando cambies o añadas un archivo: Gestionar implementaciones → lápiz → Nueva versión. Si cambias algo en la hoja, basta con recargar la web.
